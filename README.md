# IP Selector

IP Selector is a menu bar app for macOS 14 or later. It lets you quickly switch Ethernet adapters between saved IP settings without opening System Settings.

Select an attached adapter, then apply a preset with an IPv4 address, subnet mask, optional gateway, and DNS servers. You can also switch to DHCP and create, edit, import, or export presets.

The app supports Intel and Apple silicon Macs. macOS requires administrator approval for its helper before it can change network settings.
