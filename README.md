# IP Selector

IP Selector is a menu bar app for macOS 14 or later. It lets you quickly switch Ethernet and Wi-Fi adapters between saved IP settings without opening System Settings.

Each adapter has a dropdown menu for selecting from a list of user-defined presents, toggling DHCP, and quickly applying a custom IP address.

The app supports Intel and Apple silicon Macs. macOS requires administrator approval for its helper before it can change network settings.
